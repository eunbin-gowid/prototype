# 프로토타입

평소 궁금했던 기술, 라이브러리, 프레임워크를 직접 만들어 보며 동작 원리와 구조를 근본부터 공부하는 모임입니다.

공통 프로젝트나 정해진 커리큘럼 없이, 각자 공부하고 싶은 주제를 정해 작은 버전부터 직접 구현합니다.

## 목표

- 만들고 싶은 기술을 직접 구현합니다.
- AI를 활용해 실제로 동작하는 결과물을 만듭니다.
- 사용만 해봤던 기술의 내부 원리와 구조를 이해합니다.
- 작은 버전부터 시작해서 원하는 기능을 하나씩 완성합니다.
